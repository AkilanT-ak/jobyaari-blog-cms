## 📸 Features

### 🖥️ Frontend (index.html)
- 🔥 **Live News Ticker** — Scrolling latest updates
- 🎯 **Hero Section** — Stats, search bar, call-to-action
- 🔍 **Real-time Search** — Instant blog filtering
- 🏷️ **Category Filters** — Latest Jobs, Results, Admit Cards, Syllabus, Answer Keys
- 📰 **Blog Cards** — Featured + grid layout with emoji icons
- 📖 **Read More Modal** — Full blog content with rich formatting
- 📬 **Sidebar** — Upcoming deadlines, quick links, email subscribe
- 📱 **Fully Responsive** — Works perfectly on mobile & desktop

### ⚙️ Admin Panel (admin.html)
- 🔐 **Secure Login** — Username & password authentication
- 📊 **Dashboard** — Stats overview and recent blogs
- ✏️ **Rich Text Editor** — Quill.js with bold, italic, tables, bullet points, images, headings
- ➕ **Add New Blog** — Create posts with category, emoji, excerpt
- ✏️ **Edit Blog** — Update any existing post
- 🗑️ **Delete Blog** — Remove posts instantly
- 🔥 **Hot / New Badges** — Mark posts as trending or new
- 🌐 **Live Sync** — Admin changes reflect on frontend automatically

## 🚀 Getting Started

### Option 1 — Open Locally
1. Download `index.html` and `admin.html`
2. Place both files in the **same folder**
3. Open `index.html` in your browser

### Option 2 — Deploy on GitHub Pages
1. Create a new GitHub repository (set to **Public**)
2. Upload `index.html`, `admin.html`, and `README.md`
3. Go to **Settings → Pages**
4. Set Source to **Deploy from branch → main → / (root)**
5. Click **Save** — your site goes live in minutes!

## 📋 How to Add a Blog Post

1. Go to `admin.html`
2. Login with credentials
3. Click **"New Blog"** button
4. Fill in Title, Category, Emoji, Excerpt
5. Write full content in the **Rich Text Editor**
6. Toggle **Hot** or **New** badge if needed
7. Click **"Save Blog Post"**
8. Open `index.html` — your blog will appear instantly! 🎉
